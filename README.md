## Current Projects

### 1. [RAG Document Assistant](./rag-document-assistant)

A terminal-based Retrieval-Augmented Generation (RAG) pipeline using:

* OpenAI embeddings
* FAISS vector database
* LangChain
* GPT-4o

Features:

* document ingestion
* semantic retrieval
* grounded QA
* source-aware responses

Tech Stack:
Python, LangChain, OpenAI APIs, FAISS

### 2. [AI Log RCA Assistant](./ai-log-rca-assistant)

LLM-powered root cause analysis assistant for logs, crash dumps, and debugging workflows.

Planned Features:

- log preprocessing
- stack trace extraction
- AI-generated RCA summaries
- debugging recommendations
- prompt-driven crash analysis

### 3. [Build Change Intelligence](./build-change-intelligence)

AI-assisted engineering release analysis platform for summarizing build changes, risk areas, and impacted systems.

Planned Features:

- build metadata parsing
- AI-generated release summaries
- risk categorization
- impact analysis
- engineering workflow insights

### 4. MCP Agent Playground (In Progress)

Experiments involving MCP integrations, AI agents, and workflow automation pipelines.
